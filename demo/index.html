    Handwired Brain Transformer
    
    
    DANDI 000108 light-sheet human brain in Neuroglancer, with weight-programmed models running on your GPU (WebGPU).
    
    
    
    
    
    
    
    
    
    
    
    
    
    
    
    
    
    
    
    
    
    
    
    
    
    
    
    Contrast, brightness and gamma are Neuroglancer's own layer controls (the shader panel on the right: lo / hi / contrast / brightness / gamma); the model's recommended window is applied after each run. Model results are segmentation layers (voxel labels computed in your browser and served to Neuroglancer from memory): cells get one id each, vessels class labels, tissue / white matter two classes. Cell centres and extents are a hidden annotation layer you can switch on.
    
    
    Reference models (from the Neurodesk web apps): Cellpose 3 nuclei, StarDist 2D fluorescence and VesselBoost run as ONNX networks with onnxruntime-web (WebGPU, or WebAssembly on the CPU), cellfinder candidate detection is classical; weights are downloaded at run time from the Neurodesk asset store, not shipped here. They run at full resolution on tiles of the view (zoom to about 1-3 mm), the 2-D ones per plane with planes resampled so an object of the declared diameter matches the network's training size (Cellpose 17 px, StarDist 16 px), linked across z like our programs. They are slow on the CPU and are references for comparison, not ground truth; Cellpose's training data include non-commercial (CC-BY-NC) sets and VesselBoost (trained on MR angiography) states no weight licence.
